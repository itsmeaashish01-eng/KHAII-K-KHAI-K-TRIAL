Accuracy rule

This is an educational organizer, not a clinical decision tool. Any exact year, sample size, effect estimate, or citation must be verified against the original publication and guideline before academic or patient-care use.

References

How references work in this static app

Each trial card contains links to PubMed and Google Scholar searches for the trial name plus stroke. This avoids inventing exact citations. Cards with incomplete citation metadata are labeled “citation to verify.”

Educational tool only. Verify original trial publications and current AHA/ASA guidelines before clinical or academic use.
